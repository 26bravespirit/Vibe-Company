# Vibe Iteration Coach v4 — 使用说明

帮助你在AI协作中持续提升的迭代教练。无论你是第一次用AI写文档，还是已经是迭代高手，教练都会根据你的水平自动调整指导方式。

当前版本：**v4.0** | 技巧库：25 个 | 操作模式：7 个 | 评估维度：6 个（新手版 3 个）

## 第一次用？从这里开始

不需要记任何命令。直接用自然语言告诉教练你想做什么：

- "帮我写一份项目方案"
- "这个报告怎么改好"
- "我不知道怎么开始"
- "帮我优化这个文档"

教练会自动判断你的水平，给你最合适的指导。

### 你会学到的5个核心习惯

| 习惯 | 一句话 | 什么时候用 |
|------|--------|-----------|
| 先看再改 | 让AI先展示方案，你确认后再动手 | 开始任何任务时 |
| 让AI挑毛病 | 完成一版后让AI攻击它 | 写完初稿后 |
| 换个角度看 | 让AI从3个角度分析 | 感觉方案不够好时 |
| 自己做选择 | AI给选项时要主动选 | 有多个方案时 |
| 一次改一处 | 一次只改一个地方 | 需要修改时 |

### 成长路径

```
🌱 新手 → 📗 入门 → 📘 熟练 → 📕 专家
   ↑         ↑          ↑          ↑
   Core 5    解锁更多    完整6维     全部功能
   技巧      模式        评估
```

教练会自动追踪你的成长，在合适的时候解锁更多功能。

## 七种操作模式

| 模式 | 名称 | 做什么 | 新手可用 |
|------|------|--------|---------|
| Mode 0 | 🌱 新手引导 | 简化的指导流程，只介绍核心5技巧 | ✅ 自动 |
| Mode 1 | 🔍 评估 | 评估你的迭代质量并打分 | ✅ 简化版 |
| Mode 2 | 📐 规划 | 为新项目规划迭代路径 | ✅ |
| Mode 3 | ⚡ 辅助 | 迭代进行中给出下一步建议 | ✅ |
| Mode 4 | 🧭 方向 | 完成一版后探索下一版方向 | 📗 入门解锁 |
| Mode 5 | 🧰 工具箱 | 遇到痛点时推荐合适的技巧 | 📗 入门解锁 |
| Mode 6 | ✂️ 减法检查 | 检测是否过度设计 | 📘 熟练解锁 |

## 教练即时提示

每次教练指导结束后，会自动检查你的工作习惯并给出简短提示：

- 如果你一直在接受AI的方案 → 提醒你挑战它
- 如果你准备交付但没做过检查 → 提醒你花30秒验证
- 如果你反复修改同一处 → 建议换个思路
- 如果你在内容没定之前就排版 → 建议先做内容

提示会随你的成长自动减少频率——专家不需要提醒。

## 触发方式

| 你想做什么 | 怎么说 |
|-----------|--------|
| 第一次用，需要指导 | "我不知道怎么开始" / "帮我优化这个" |
| 评估迭代质量 | "评估一下我的迭代" / "evaluate my iteration" |
| 规划迭代策略 | "帮我规划迭代策略" / "plan my iteration" |
| 迭代中卡住了 | "下一步该怎么做" / "I'm stuck" |
| 规划下一版方向 | "给我迭代方向" / "what should v4 look like" |
| 不知道该用什么技巧 | "该用什么技巧" / "which technique should I use" |
| 怀疑过度设计 | "检查过饱和" / "reduction check" |
| 查看教练日志 | "看看我的教练日志" / "my iteration trends" |
