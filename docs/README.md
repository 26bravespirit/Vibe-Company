# Vibe Iteration Coach — 使用说明

一个帮助你在多轮 AI 协作中持续提升迭代质量的教练 Skill。适用于组织设计、商业计划、产品 PRD、战略规划、投资分析、品牌设计、技术架构等需要多版本迭代的复杂项目。

当前版本：**v3.1** | 技巧库：25 个 | 操作模式：6 个 | 评估维度：6 个

## 快速开始

安装 `.skill` 文件后，在对话中用自然语言触发即可。不需要记住具体命令——教练会根据你的描述自动判断该进入哪个模式。

**常用触发方式：**

| 你想做什么 | 怎么说 |
|-----------|--------|
| 评估迭代质量 | "评估一下我的迭代" / "evaluate my iteration" |
| 规划迭代策略 | "帮我规划迭代策略" / "plan my iteration" |
| 迭代中卡住了 | "下一步该怎么做" / "I'm stuck" |
| 规划下一版方向 | "给我迭代方向" / "what should v4 look like" |
| 不知道该用什么技巧 | "该用什么技巧" / "which technique should I use" |
| 怀疑过度设计 | "检查过饱和" / "reduction check" |
| 查看教练日志 | "看看我的教练日志" / "my iteration trends" |

## 六种操作模式

### Mode 1: 🔍 Review — "我做得怎么样？"

评估你的迭代过程。教练会从 6 个维度（意图传递、迭代节奏、批判性思维、框架构建、主导权、产出物管理）打分，满分 60 分，并指出你用了哪些技巧、漏掉了哪些。

如果教练日志中积累了 3 条以上记录，还会额外输出长期趋势分析：得分走势、技巧盲区、反模式复发率。

### Mode 2: 📐 Plan — "我该怎么入手？"

为新项目规划迭代路径。教练会根据项目类型（12 种场景映射）推荐最相关的技巧子集，设计分阶段的迭代路线图，并列出关键决策检查点。

### Mode 3: ⚡ Assist — "下一步做什么？"

迭代进行中需要指导。教练会判断你处于迭代生命周期的哪个阶段，识别你的行为模式（是不是一直在扩张没有收缩？是不是迭代了很多轮但没有做过批判性评审？），推荐最有影响力的下一个技巧。

### Mode 4: 🧭 Navigate — "下个版本往哪走？"

完成一个版本后不知道下一步该怎么突破。这是最常见的卡点——你知道当前版本"能用"，但感觉还差点什么。

教练会生成 10 个方向：5 个基于第一性原理（挖掘本质），5 个基于创意驱动（打破常规）。每个方向都有难度和突破潜力评级。你选择 1-2 个方向后，教练自动切换到 Plan 模式帮你规划实施路线。

### Mode 5: 🧰 Toolkit — "该用哪个技巧？"

迭代中遇到具体痛点但不知道该用 25 个技巧中的哪个。教练作为"症状检查器"运作：你描述当前问题，教练匹配到 17 种症状模式之一，开出 2-3 个技巧处方，每个处方都带一个"现在就这么做"的具体行动。

### Mode 6: ✂️ Reduction Check — "是不是过度设计了？"

经过多轮迭代后，产出物可能累积了不必要的复杂度。教练提供量化回答：先锚定第一性原理，然后对每个设计元素评分（基于离第一性原理的距离），输出饱和度指数（0-100），对高分元素给出具体处方（删除、合并、降级、重构）。

## 5 步核心循环

每次成功的复杂迭代都遵循这个节奏：

```
① 提出（PROPOSE）— 用户提出核心概念或方向
② 压力测试（STRESS）— AI 正反论证、填充细节、攻击弱点
③ 萃取（EXTRACT）— 用户从 AI 的论证中捕获洞察
④ 决策（DECIDE）— 用户做出显式选择并执行
⑤ 验证（VERIFY）— 用户检查全局一致性
```

然后回到 ①。大多数人卡在 ①→②→①→② 的循环里，从来没有走到 ③④⑤。教练会帮你识别你在哪一步，以及你跳过了哪一步。

## 6 维评估框架

| 维度 | 评估什么 | 满分 |
|------|---------|------|
| D1 意图传递 | 提示词是否精确传达了你的意图 | 10 |
| D2 迭代节奏 | 推进、回退、扩张、收缩的节奏是否有效 | 10 |
| D3 批判性思维 | 是否主动挑战 AI 并发现盲区 | 10 |
| D4 框架构建 | 是否创建了可复用的结构而非一次性补丁 | 10 |
| D5 主导权把控 | 是你在引导 AI 还是 AI 在引导你 | 10 |
| D6 产出物管理 | 版本控制、命名、跨文件一致性 | 10 |

**评级标准：** 54-60 S 级（标杆）/ 42-53 A 级（优秀）/ 30-41 B 级（良好）/ 18-29 C 级（需改进）/ <18 D 级

## 教练日志

每次教练互动后，系统会自动在 `vibe-iteration-log.md` 中追加一条记录，包含使用的模式、技巧、得分、反模式检测等元数据。你不需要手动维护。

日志的价值在"回看"：当你在 Mode 1 Review 中积累了足够的记录后，教练会自动输出长期趋势分析，帮你看到自己作为迭代者的进化轨迹——哪些维度在进步、哪些技巧是盲区、哪些坏习惯在反复出现。

## 模式流转

```
🧭 Navigate（方向）→ 📐 Plan（规划）→ ⚡ Assist（执行中指导）→ 🔍 Review（评估）→ 回到 Navigate
                                              ↕
                                    🧰 Toolkit（技巧选择）
                                    ✂️ Reduction（过饱和检测）
                                    （随时可调用）
                    ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
                    📝 Persistence Layer（自动记录每次互动）
```

可以从任意模式进入。Navigate 在大版本之间特别有价值。Toolkit 和 Reduction Check 是随时可调用的工具模式。

## 九条教练原则

1. **不替你做。** 教练推荐技巧，不替你执行项目。
2. **先诊断再开方。** 理解你在迭代的哪个阶段，再建议下一步。
3. **庆祝版本跳跃。** 范式级跳跃是最有价值的时刻。
4. **警惕主导权陷阱。** 如果你在不加思考地接受 AI 建议，教练会提醒你。
5. **保持实用。** 不一次讲 25 个技巧，只推荐当下最需要的 1-2 个。
6. **Navigate 生成方向，用户做选择。** 教练不排名，不推荐"最佳"方向。
7. **Toolkit 开的是行动处方，不是理论讲座。** 每个推荐必须带一个"现在就这么做"的具体行动。
8. **Reduction Check 量化而非凭感觉。** "感觉太复杂"不可操作，"饱和度 42，3 个 L4 元素贡献了 60% 的分数"才可操作。
9. **日志自动记，分析按需看。** 不让日志记录打断教练流程，长期趋势只在 Review 中呈现。
